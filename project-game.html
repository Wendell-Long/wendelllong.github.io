Build your game - Whack-a-Mole

Individueel project beheerd via de Scrum-methodiek

Gebruikte Technologieën & Methodieken:

HTML5 CSS3 JavaScript (ES6) Scrum Process

Projectomschrijving:

Voor het project "Build your game" heb ik individueel een interactieve 2D Whack-a-Mole) game ontwikkeld. Hoewel dit een individuele opdracht was, heb ik de Scrum-methodiek toegepast om mijn eigen ontwikkelproces te structureren. Door middel van een persoonlijke backlog heb ik features zoals de scoretelling, de aftellende timer en de moeilijkheidsgraad stapsgewijs gerealiseerd binnen de gestelde sprints.

Complexe JavaScript Logica:

Dit project bevat complexe front-end logica aangedreven door JavaScript (ES6). De kern van de game draait om een algoritme dat via Math.random() willekeurig gaten selecteert waar de mollen voor een beperkte tijd verschijnen. Om raceconditions en overlappende timers te voorkomen, is er strikt gebruikgemaakt van gecoördineerde setInterval en setTimeout functies.

Daarnaast is er een score-validatiesysteem gebouwd: via event listeners wordt gecontroleerd of de gebruiker daadwerkelijk binnen de actieve tijd op de mol klikt. Bij een succesvolle 'hit' wordt de score realtime in de DOM bijgewerkt, terwijl een centrale gameloop de resterende tijd bewaakt en het spel netjes beëindigt wanneer de timer de nul bereikt.
