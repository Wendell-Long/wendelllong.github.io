Mon-in

Full-stack webapplicatie met database-interactie

Gebruikte Technologieën & Concepten:

PHP (OOP / PDO) MySQL / SQL Bootstrap 5 Session Management CRUD-architectuur

Projectomschrijving:

Mon-in is een full-stack webapplicatie die functioneert als een intern sociaal portaal. Binnen dit project lag de focus volledig op de backend-architectuur en de veilige uitwisseling van data tussen de server en de relationele database. Gebruikers kunnen via het systeem een account aanmaken, inloggen, hun profiel beheren en realtime berichten (posts) delen op een centrale tijdlijn.

Backend Implementatie & Database Veiligheid:

De backend is volledig geprogrammeerd in PHP, waarbij de databaseverbinding tot stand is gebracht via PDO (PHP Data Objects) met strikte foutafhandeling (ERRMODE_EXCEPTION). Om de applicatie te beschermen tegen kwaadaardige SQL-injections, zijn alle database-queries uitgerust met Prepared Statements en named parameters (zoals :email en :content).

Voor het gebruikersbeheer is een functioneel Session Management opgezet via session_start(), wat zorgt voor beveiligde pagina-restricties (ongeautoriseerde gebruikers worden direct omgeleid naar de login-pagina). Bij het ophalen van de data op de hoofdpagina is er gebruikgemaakt van complexe SQL JOIN-clausules om de post-content direct te koppelen aan de juiste gebruikersgegevens (zoals avatars en namen). Tot slot is Cross-Site Scripting (XSS) effectief geblokkeerd door systematische toepassing van htmlspecialchars() tijdens de HTML-outputfase.
