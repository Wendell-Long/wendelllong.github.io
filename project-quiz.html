Quiz Game

Gerealiseerd in teamverband via de Scrum-methodiek

Gebruikte Technologieën & Methodieken:

HTML5 CSS3 JavaScript (ES6) Scrum Git

Projectomschrijving:

De Quiz Game is een interactieve, front-end webapplicatie die is ontwikkeld als een groepsopdracht binnen de opleiding Software Developer. Het doel van het project was het bouwen van een dynamisch vraag-en-antwoordsysteem waarin gebruikers hun kennis kunnen testen op een intuïtieve interface.

Tijdens de ontwikkeling hebben we strikt gewerkt volgens de Scrum-methodiek. In sprints hebben we de functionaliteiten opgedeeld via een product backlog. Denk hierbij aan user stories voor het inladen van de vragen, de timer-logica, en het berekenen van de uiteindelijke score. Dit project heeft mijn vaardigheden op het gebied van teamcommunicatie, versiebeheer via Git, en taakverdeling aanzienlijk versterkt.

Technische Realisatie:

De applicatie maakt intensief gebruik van JavaScript (ES6) om de DOM dynamisch te manipuleren. Vragen worden opgeslagen en uitgelezen via objecten en arrays. Door middel van event listeners wordt de invoer van de gebruiker direct gevalideerd (juist/onjuist), waarna de interface zonder pagina-reload (re-render) wordt bijgewerkt naar de volgende vraag. CSS3 is ingezet om de lay-out clean en responsive te houden.
